# AI Risk Manager

AI Risk Manager is a merchant-loss reduction platform focused on chargebacks, risk scoring, and intelligent evidence-grounded dispute defense.

## Architecture

- **Frontend**: React + Vite + Tailwind CSS + Lucide React (`/frontend`)
- **Backend API Gateway**: Node.js + Express + Mongoose + JWT (`/backend`)
- **ML Microservice**: Python + FastAPI + Scikit-Learn + XGBoost (`/ml_service`)
- **Database**: MongoDB
