Running the AI Risk Manager Services

Based on the project structure, here's how to run each service:

1. Frontend (React + Vite)

// bash
cd frontend
npm install          # Install dependencies
npm run dev          # Start development server on http://localhost:5173

Environment setup:
- Copy  .env.example  to  .env 
- The frontend connects to the backend at  http://localhost:5000/api 

2. Backend (Node.js + Express)

// bash
cd backend
npm install          # Install dependencies
npm run dev          # Start with nodemon (development mode)
# OR
npm start            # Start production mode

Environment setup:
- Copy  .env.example  to  .env 
- Requires MongoDB running on  mongodb://localhost:27017/ai_risk_manager 
- JWT secret and other config in  .env 
- Runs on port 5000 by default

Database seeding:

// bash
npm run seed         # Populate database with sample data

3. ML Service (Python + FastAPI)

// bash
cd ml-service
python -m venv venv   # Create virtual environment
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt  # Install Python dependencies
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
